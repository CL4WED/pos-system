# Laravel POS Application

A simple Laravel POS application created for IT0049 Technical Formative Assessment 5.

## Features

- Landing page
- About page
- Customer Accounts page
- User Accounts page
- Navigation between pages
- Static PHP arrays displayed using Blade @foreach

## How to Run

1. Download or clone this repository.
2. Open the project folder in a terminal.
3. Run:

   ```bash
   composer install
   php artisan serve
